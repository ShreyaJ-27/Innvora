# StockPulse — Visual Inventory Health & Smart Reordering Platform

StockPulse is a modern, real-time inventory operations platform designed for independent store owners, warehouse operations leads, and multi-channel D2C managers.

## Repository Layout
- `frontend/` - React + Vite + TypeScript frontend dashboard and design system
- `backend/` - Core API server and route handlers
- `infrastructure/` - AWS CDK / Terraform infrastructure definitions
- `lambdas/` - Serverless event processors & SQS handlers
- `scripts/` - Automation & seed utilities
- `docs/` - System architecture & API contracts
- `sample-data/` - Sample inventory datasets & simulation schemas

## Frontend Quickstart
```bash
cd frontend
npm install
npm run dev
```
