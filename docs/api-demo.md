# StockPulse API Demonstration Guide

All API endpoints are hosted at:
`https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod`

---

## 1. Inventory Health Summary

### `GET /inventory/health`
Returns SKU count and aggregate health status across all active hubs.

```bash
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory/health"
```

**Example Response (200 OK):**
```json
{
  "success": true,
  "data": {
    "totalSkus": 12,
    "healthy": 13,
    "reorderSoon": 8,
    "critical": 9,
    "overstocked": 6
  }
}
```

---

## 2. List Inventory

### `GET /inventory`
List paginated inventory records. Supports filtering by location and health status.

```bash
# List first 25 items across all locations
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory?limit=25"

# Filter by location and critical status
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory?locationId=LOC-BLR-01&status=critical"
```

---

## 3. Smart Reorder Recommendations

### `GET /reorders`
Retrieves explainable replenishment recommendations generated by the reorder engine.

```bash
# All recommendations sorted by urgency (CRITICAL -> REORDER_SOON -> HEALTHY -> OVERSTOCKED)
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/reorders?limit=25"

# Filter only CRITICAL urgency items
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/reorders?urgency=CRITICAL"
```

## 4. Search Historical Events (OpenSearch)

### `GET /inventory/search`
Queries OpenSearch index for historical audit events.

```bash
# Full text search for "Wireless"
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory/search?q=Wireless"

# Filter by event type and SKU
curl -X GET "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory/search?sku=SKU-EAR-001&eventType=RESTOCK"
```

## 5. Post Inventory Event (Async Pipeline)

### `POST /inventory/events`
Dispatches an inventory change into the API Gateway → SQS → Lambda processor pipeline.

```bash
curl -X POST "https://1d1j9fcft5.execute-api.ap-south-1.amazonaws.com/prod/inventory/events" \
  -H "Content-Type: application/json" \
  -d '{
    "eventId": "evt-live-demo-001",
    "productId": "PROD-EAR-01",
    "sku": "SKU-EAR-001",
    "locationId": "LOC-BLR-01",
    "eventType": "RESTOCK",
    "quantityChange": 20,
    "timestamp": "2026-09-20T12:00:00.000Z",
    "source": "Manual Restock Webhook"
  }'
```

**Response (202 Accepted):**
```json
{
  "success": true,
  "eventId": "evt-live-demo-001",
  "message": "Inventory event accepted for processing."
}
```
*Note: Changes reflect asynchronously after SQS consumption.*
